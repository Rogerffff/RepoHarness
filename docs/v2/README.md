# RepoHarness V2 Documents

这个目录收纳第二版范围、路线图和后续实施计划相关文档。

- `scope-and-roadmap.md`：第二版范围设计、优先级、接口演进、成功标准、非目标和建议实施顺序。
- `implementation-plan.md`：第二版详细工程实施计划、阶段拆分、测试矩阵、风险和最小完成定义。

后续实施第二版时，应持续以 `scope-and-roadmap.md` 和 `implementation-plan.md` 中的产品能力验收、研究评测验收和工程质量验收作为边界，避免把 Docker execution mode、完整公开榜单复现、复杂后台多代理平台或新强化学习算法提前纳入核心交付范围。
