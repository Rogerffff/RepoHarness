Runtime 入口 + AgentLoop 多轮调度

本页详解一条 episode 进入 RepoHarness 后的完整执行：verl AgentLoopWorker 怎么调到 RepoHarnessVerlAgentLoop，kwargs 怎么校验和构造 RepoHarnessEpisodeRequest，runtime 怎么分发到 minimal_gateway 还是 real_episode，real_episode 内部怎么用受控 executor把 AgentLoop 同步循环包起来，LLMGatewayModelClientAdapter 怎么作为跨线程桥让同步 AgentLoop 调到 async LLMGateway，GenerationRecordCollector 怎么跨多轮把每一次模型生成的 token 事实保存下来。

② kwargs 校验 + 安全 id 构造

verl 传入的 kwargs 可能含不可信字段（恶意 / hidden / 绝对路径），request_mapping.py 用 allowlist + 正则替换确保只有安全字段进 RepoHarnessEpisodeRequest。

validate_repo_harness_verl_kwargs · allowlist

仅允许 ~20 个明确字段（task_id / repo_ref / base_commit / prompt / budgets / inference_backend 等）。其它字段（特别是 raw_prompt / kwargs 中残留的 verl 内部控制字段）会被静默丢弃或显式拒绝。详见 request_mapping.py:27-86。

build_safe_episode_identifiers · 正则替换非法字符

verl 传入的 task_id / episode_id 可能含 /、空格、unicode 字符。这些 id 会被用作文件路径片段（如 leases/<key>/<episode_id>），必须规范化。

minimal_gateway

1 turn LLM call + Stage 7 reward boundary，不跑真实 workspace / agent loop / verifier。

用途：contract / adapter / DataProto shape smoke。禁止声称完整软件工程任务闭环。

Stage 2-10 单元测试都用这条路径。

real_episode ⭐

Stage 11.5 引入，真实跑 workspace + AgentLoop + tool + verifier + reward。

用途：Stage 12 端到端 smoke 唯一可信凭证。

必要注入：source_resolver + snapshot_manager + final_verifier_factory（来自 options）。

⑦ LLMGatewayModelClientAdapter（Stage 2 + Stage 11.5 关键增强）

这是跨同步/异步层的核心桥。同步 AgentLoop 看见的是 model_client.generate(...) 接口；adapter 内部用 run_coroutine_threadsafe 调到 async LLMGateway.generate_turn，再把结果转回同步对象。Stage 11.5 加了 generation_record_collector 参数让每次跨线程调用都自动 collect。

def _run_gateway_turn_blocking(gateway, request, *, resource_lease_manager, resource_handle, runtime_loop): # 关键：在 worker thread 里要调 async，必须用 run_coroutine_threadsafe # 不能用 asyncio.run（会创建新 loop，导致 server_manager 找不到原 loop 的资源） coro = _generate_gateway_turn(gateway, request, resource_lease_manager=..., resource_handle=...) future = asyncio.run_coroutine_threadsafe(coro, runtime_loop) return future.result() # 阻塞 worker thread 直到 runtime_loop 跑完 coro
为什么需要 runtime_loop verl server_manager 内部维护异步连接，必须在原 event loop 上跑。worker thread 用 asyncio.run 会创建新 loop → server_manager 找不到 transport → fails。
