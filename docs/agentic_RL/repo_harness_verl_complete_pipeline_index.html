链路结论主要 evidence解释边界
真实远端 trainer 已经执行完整训练步 runs/stage12_6-remote-20260517T150036Z/stage12_6_acceptance_summary.json 证据显示完成 2 个 global step；这不同于“3 条 episode 进入 batch”。
真实 RepoHarness episode 可以进入同一个 verl batch runs/stage12c-real-batch-20260516T230434Z/stage12c_real_batch_acceptance_summary.json 这里的数字是 3 条真实 Qwen2.5-Coder episode，不是 trainer global step 数。
formal online RL 样本必须来自 verl 路由并带 logprobs validate_formal_online_rl_batch 与 episode_result_to_agent_loop_output(..., formal_online_rl=True) 这道门保证 mock、缺失 log probability、visibility 违规样本不会进入正式 PPO/GRPO 路径。
本地路径、workspace 路径和 run directory 不进入训练 batch project_audit_refs_for_extra_fields、visibility report、conversion allowlist batch 里只保留 repo_harness_*_ref 这类 opaque reference，真实路径只在 runtime 内部使用。
Stage 12.5 本地 evidence 齐全但不等于最终通过 runs/stage12_5-local-20260517T023945Z/stage12_5_local_acceptance_summary.json 该 summary 的 evidence_complete=true，但 acceptance_ready=false，原因是工作区 dirty 或存在 untracked 文件。
Stage 12.5 / 12.6 远端 evidence 支撑进入后续异步改造 远端 acceptance summary、trainer throughput profile、14 个远端 evidence 文件 profile helper 是诊断和验收能力，不应描述成已经固定插入 trainer loss 主链路的自动落盘逻辑。
