Contract 03 为什么必须存在

TrainingView

它是从完整 RepoHarnessEpisodeResult 中投影出的训练视图。verl adapter 不应该自己绕过 episode result 拼训练字段，而应该消费这个视图并转换成 AgentLoopOutput。

GenerationRecord

它记录每一轮模型调用的来源证据。route=verl 时，它把 LLMGatewayResponse 和真实 rollout generation 路径绑定起来，避免后续用最终 transcript 重新分词伪造训练 token。

AuditRef

它让训练样本能回到完整审计材料。训练后端拿到的是轻量输出，但需要能够追溯 transcript、events、artifact manifest、reward metadata、final verifier、patch 和 timing/resource 结果。
