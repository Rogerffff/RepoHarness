状态徽章：✅已有=已实现完整 · ✅行为已实现=本 stage 完成行为 · ✅行为+投影已通=run_episode → final.patch 端到端通 · 🟡当前 partial=有但形态不完整 · 🔧待建=尚未实现 · 🩺仅诊断=只在诊断旁路 · ⏸预留=只 schema。
