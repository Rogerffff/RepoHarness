## 新增判据与实现边界

公开 `numpy/core/arrayprint.py:62–67` 将 `threshold` 定义为触发摘要的总元素数阈值，将 `edgeitems` 定义为每维首尾保留项数；`:252–257` 的判断是严格 `size > threshold`；`:473` 附近只在有摘要标记且 `2 * edgeitems < len(a)` 时插入省略号。公开 Quickstart `doc/source/user/quickstart.rst:262–267` 允许通过打印选项要求全量显示。这些是本题行为依据，不依赖 gold 或私有补丁。

- **n=3000／threshold=2000**：原数组仍超过阈值，首尾默认各三项，中间应有省略号；遮蔽索引 1–49 后，`[0 -- -- ..., 2997 2998 2999]` 与公开逻辑一致。这个场景只补旧审查已登记的同族漏判，不增加新任务目标。
- **n=3000／threshold=1000／edgeitems=501**：应显示索引 0–500、一个省略号、2499–2999。新断言的期望共 1003 个 token，遮蔽数量仍为 49；去除括号、逗号并按空白分词允许正常折行，没有绑定补丁常量或内部接口。
- 两项都追加在既有 `TestMaskedArray.test_str_repr` 的打印选项 `try/finally` 中；原设置恢复仍在 `finally`。未改变其它测试函数或扩大为二维／性能验收。

**K-A5c 的静态理由成立。** 对本轮使用的非负整数 threshold 与 edgeitems，超过阈值时取宽度 `max(原宽度, threshold+2, 2*edgeitems+2)`，截取后实际长度为 `2 * floor(width/2)`，仍严格大于阈值和 `2*edgeitems`。因此原 arrayprint 可插入省略号，同时首尾所需项数仍在截取结果中。若原长度不足以截取，则保留原数据；未超过阈值时宽度等于原长度，不先丢值。n=3000／t=2000 留 1001 项首部和 1001 项尾部；大 edgeitems 场景留各 502 项，最终交给 arrayprint 显示各 501 项。没有使用模块内已被覆盖的裸 `max`。

该补丁仍只改变 `ndim == 1`、普通 dtype 且存在 mask 的既有截角路径；structured dtype、无 mask 和多维分支沿用原行为。未见明显无谓的行为变化。这个判断不扩大为所有打印配置、dtype、子类或性能的完整正确性证明。

**hybrid 的父版 1／新版 0 是合理静态预期。** 父版要求的默认大数组摘要仍可由 1500 项截取触发，默认 n=500 和 t=2000／n=2000 又完全保留；它不触发已知父版三处新增断言。新 n=3000／t=2000 被截成 1500 项后低于阈值，arrayprint 会全量显示截取结果、没有省略号，必然与新摘要断言冲突。229 键整体得 1 仍属待运行预期，不以这条局部推导替代正式矩阵。

**旧 K-A5b 新版 0 合理。** 默认阈值下截取后为 1002 项，恰好等于 `2*501`；arrayprint 的省略条件是严格小于，因而输出首尾 1002 项却没有省略号。新大 edgeitems token 断言可以拒绝它。其旧版正式得 1 的记录不回写；本轮也不再把它当主正对照。
