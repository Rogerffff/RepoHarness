## 问题与修法

RGB 图的 `info["transparency"]` 是元组且量化后无法分配透明调色板项时，保存 GIF 应不抛异常，输出不使用透明度。能使用的透明色仍应保留，保存不能改坏调用者图像或依赖之前保存的缓存；保留既有公开警告行为。

原始测试只有题面示例，已证实漏过硬编码、只修部分输入、过度丢弃和修改调用者状态等错误候选。采用云端独立复核者最终 v2，而非作者旧 v1：

- 修订测试 `3573f459…`，父原件 `ff7a439c…`。
- 93 键期望文件 `a465b6c9…` 不变。
- 在既有目标函数追加检查，覆盖非示例照片、满调色板已有透明色、调用者 `info`、`save_all=True` 单帧和连续保存同一透明色。
- `pytest.warns(UserWarning)` 保留，只要求有警告，不规定文案。这个取舍已有独立意见，不重新请用户决定。
