### ProxyConnector Drops Port from Request Path

**Description**

When using `ProxyConnector` to establish a connection with a URL that includes a specific port, the port number is omitted from the request path. This results in the request being sent to an incorrect URL without the designated port.

**Example Code**

The example replaces the transport connection with a completed Future, so it runs without contacting the proxy. It still exercises ProxyConnector.connect().

```python
import asyncio
from unittest import mock
from aiohttp import ProxyConnector
from aiohttp.client import ClientRequest

loop = asyncio.new_event_loop()
transport, protocol = mock.Mock(), mock.Mock()
connected = loop.create_future()
connected.set_result((transport, protocol))
transport_loop = mock.Mock()
transport_loop.create_connection.return_value = connected
connector = ProxyConnector('http://proxy.example.com', loop=transport_loop)
try:
    req = ClientRequest('GET', 'http://localhost:1234/path', loop=loop)
    loop.run_until_complete(connector.connect(req))
    print(req.path)
    assert req.path == 'http://localhost:1234/path'
finally:
    connector.close()
    loop.close()
```

**Expected Behavior**

The `req.path` should retain the port number, resulting in:
```
'http://localhost:1234/path'
```

**Actual Behavior**

The `req.path` drops the port number, resulting in:
```
'http://localhost/path'
```
