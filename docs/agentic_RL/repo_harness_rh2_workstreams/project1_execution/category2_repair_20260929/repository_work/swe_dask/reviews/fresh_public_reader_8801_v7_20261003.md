## 实际发现：空配置的合法范围未完全定义

严重度：局部语义歧义；不阻止主问题开发。

证据是两句并列规则：顶层不是键值映射的内容应失败，而空配置仍合法。`[]` 和 `""` 在通常的 YAML 表达中分别是空序列与空字符串，都不是映射，也可被普通读者称为“空”。显式 `null` 同样没有键值映射结构；如果解析器把空文档与显式 `null` 解析为同一个空值，是否需要区分二者，文字也未说明。

一种合理理解是仅接受空映射与没有配置条目的空文档；另一种理解是继续接受若干解析结果为空的文档。两者可能对 `[]`、`""`、`null` 作出不同处理。单凭公开文字不能把其中一方的全部边界判断认定为必然错误。

如果这些边界参与验收，建议在题面明确空文档、仅注释文档、空映射、显式 `null`、空序列和空字符串各自属于哪类。应由行为约束直接说明，而非通过指定 truthiness 判断、异常类或源码结构来暗示答案。本核查不替任务作者决定这些边界。
