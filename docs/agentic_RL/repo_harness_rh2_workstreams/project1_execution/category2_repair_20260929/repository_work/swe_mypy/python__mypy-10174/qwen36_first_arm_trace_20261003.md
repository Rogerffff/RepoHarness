## 方法、定位与纠错

模型先复现公开的`Optional[Any]`容器检查误报（第2个工具），在第22个工具找到`dangerous_comparison`，第25–28个工具找到`meet.is_overlapping_types`和去除None的`UnionType.relevant_items`。第54个工具的动态诊断明确显示：`Union[Any, None]`先绕过Any早期检查，随后去除None成为Any，但最后仍返回不重叠。第56个工具在去除None后再次判断Any并返回重叠；正式源码改动集中于`mypy/meet.py`。这与公开症状具有可追溯的因果关系。
