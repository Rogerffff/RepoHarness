每题持续负责到“已知影响合理求解或评分的缺陷已处理，实际版本与证据对齐，可以移交普通探针”，或形成具体阻塞与解除条件。不能用“受限比较”“事后人工审计”替代已确认缺陷的修复。CPU验收通过仍不是训练资格，也不证明模型一定能解题。

每个修订都先利用已有材料与结果，只补受影响路径：公开开发操作、正确修法、noop，以及能触发已知漏洞的错误候选。需要正式评分时，验证测试确实执行、参考键与测试身份一致、安装子命令与测试实际退出、完整日志和容器清理。改变题面另由未接触私有材料的公开读者检查。最终用独立复核确认后，向第1类线程交付版本、限制和证据，不能仅转发旧 `probe_ready` 标签。
