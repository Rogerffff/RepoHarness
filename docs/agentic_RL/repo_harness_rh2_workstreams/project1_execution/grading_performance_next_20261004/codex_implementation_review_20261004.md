## 2. 本轮需要修复的三项

### F1 · P1：缓存内部临时路径故障会新增编译失败

**位置：**[交付 prepared_image.py](../../../../../runs/grading_performance_next_20261004/codex_impl_review_20261004/integration/rh2/src/repoharness2/grading/prepared_image.py) 第 264–270 行，`build_cache_layer_script` 生成的 v2 包装器。

**当前行为和证据：**包装器只检查 ccache 执行位及私有目录顶层可写／可进入，随后 `exec ccache`。主审在真实 cpu-c、最终模板、ccache 4.14.1、正式候选 UID、断网容器内，将 `/tmp/rh2-ccache/tmp` 建为普通文件；顶层检查仍通过，ccache 返回 `Not a directory`，包装器返回 1、没有目标文件，同一源码直接调用原 GCC 返回 0。正常情况及私有 `ccache.conf` 伪造对照均返回 0、对象一致。

**违反的约束与影响：**缓存是性能优化，私有缓存环境故障应旁路到原编译器，不能使原本能编译的候选新增失败。这是已启用实验包装器的真实可达故障；候选构建脚本可以在自己的 `/tmp` 形成该形状，不依赖写共享缓存或宿主权限。当前 Pandas 安装脚本另有吞掉早期失败的问题，可能继续测试旧 `.so`；那是既有 B 线问题，不能据此接受新增编译失败。本轮没有跑出一条实际错误 reward。

**最小修复／分期：**本批修。针对已证的内部临时路径准备失败旁路缓存，或在现有私有目录内提供真正可用的隔离临时路径；保留原编译器、原期限和真实源码错误。不要对所有非零退出一律重新编译，也不要增加候选拒绝或另建缓存服务。

**复现与验收：**[cpu_narrow_probe_v2.py](../../../../../runs/grading_performance_next_20261004/codex_impl_review_20261004/cpu_narrow_probe_v2.py) 经现存 `cpu_slot` 运行，原件 [cpu_probe_result_v2.json](../../../../../runs/grading_performance_next_20261004/codex_impl_review_20261004/cpu_probe_result_v2.json)。修后须同时满足：正常真命中；顶层不可写／内部 tmp 文件碰撞时与原 GCC 一致；真实语法错误仍失败且不重复编译；容器和期限收口。仅 helper 替身通过不够。

## 3. 实验完成口径和剩余范围

### E2 需要收窄为已实际覆盖的机制

“十组反例全部证明编译正确”不成立。v5 删除 `.pyx` 后在 metadata 阶段失败，**零编译、零链接**；相同 `.so` 是同样留下原镜像产物，不是删除源码后的成功重编。v1 仅 Python 改动也不是一次新的 cache／nocache 配对，其扩展参照是 v0。

v10 的 64 次编译只有 63 个 hit／miss 记录。主审用同版本 ccache、同一 Pandas `properties.c` 编译命令做窄验：把 C 文件设为未来时间后，hit／miss 不增加，完整统计 `modified_input_file` 增加 1，实际调用编译器。它支持“未来 mtime 绕过缓存”的解释；原 v10 缺完整统计，不能倒填成已测到该计数，更不能把它称为正常缓存键失效证明。

主审另用真实 baseline 重建＋`_apply_frozen_delta` 应用单文件 C 内容变更，再设旧 mtime；新对象含新标记、不同于基线对象、与禁用缓存的对象逐字节一致。此探针覆盖实际冻结传输到一个翻译单元；基线单编译本身为 miss，**不声称它验证了已预热键的命中再失效，也不等于全套 Pandas 评分**。完整 `.pyx`／头文件反控采用作者原始日志重核，本次未重跑整套十组。

证据：[单翻译单元探针](../../../../../runs/grading_performance_next_20261004/codex_impl_review_20261004/cpu_frozen_compile_probe.py)、[结果](../../../../../runs/grading_performance_next_20261004/codex_impl_review_20261004/cpu_frozen_result.json)。FrozenPatch 没有 mtime 字段，E2 的手工时间设置必须与正常 FrozenPatch 重放分开描述。
