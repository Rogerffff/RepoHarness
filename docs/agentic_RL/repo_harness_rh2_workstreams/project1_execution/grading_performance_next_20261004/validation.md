## 已核对的设计事实

- v13交付为真实 frozen_code_v8 的文件父版，不以Git HEAD替代；工作副本的23个交付文件与最终manifest一致。
- 当前原容器恢复完整工作树并清理HOME／临时目录，不能称为已保留actor新编译成果。
- 冻结前已有会话排空、进程归零和双读稳定屏障。已修正初稿顺序，明确先静止再导出／持久化FrozenPatch；评分侧仍另有撤网和第二次停止复证。
- Prime当前是从创建起断网的独立grader。固定SDK已有user进程接口，但网络策略更新不自动撤销已有连接，线上交接未验证。
- 树外可信缓存优先；若修改基线，必须另做环境资格，不改旧FrozenPatch摘要。缓存失败回原全量构建，不能新增正常编译型轨迹的拒绝规则。
- 3→5次补跑只适用于E1指定Pandas档位和E3本地配对。E4/E5/E6各自固定次数，不隐含扩量。
- DVC资格是E6独立前置；E6统一prepared fresh，不因复用成功而换模式。
- 创建数按实际资源核算：E5为9个开发／评分实例＋3个DVC资格实例＋1个快照恢复实例；阶段B为13＋144＋3=160。阶段A最多8，A+B累计168。B继承每实例2 vCPU／4 GiB／40 GiB、TTL≤60分钟。公开运行费率估算不冒充总账单保证。
