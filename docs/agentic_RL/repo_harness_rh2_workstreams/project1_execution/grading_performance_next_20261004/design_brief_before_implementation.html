为什么基线摘要相同，还不能直接跳过 Git 清理？

当前 Git 排除区摘要只核对路径名，不核对文件内容。可信模板还必须绑定源镜像、清理脚本、工具版本和实际内容，保留清理自证；证明缺失时走原清理。

为什么不直接保留 actor 编好的 .so？

actor 指执行开发任务的 agent。当前 Pandas 安装命令每次在新的临时目录编译，已有 .so 没有避免这些调用。优先尝试编译器层缓存；缓存还必须对应最终源码，不能继承 actor 留下的任意私有缓存。
