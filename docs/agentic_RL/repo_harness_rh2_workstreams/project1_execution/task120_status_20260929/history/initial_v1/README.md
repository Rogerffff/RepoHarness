读表的几个必要区别：

- **37题“题面／范围”不代表37题都写错了。**其中包含原例不能复现、症状表述偏差，以及公开要求和验收的关系尚需核定。下一步分类为范围核定的20题单列在下表，其余可能已有允许保留的限制。
- **13题“开发限制”不代表13题完全不能开发。**例如旧 pytest／Twisted 导致部分公开测试失败，但相应题卡已有可用开发路径；当前明确挡住收口的例子是 Pillow2d01。未做 actor 验证不贴“环境坏了”标签。
- **3题是当前证据足以确认的不当验收约束，不是3题都已有模型误拒。**Pandas50319 是公开原文与验收直接不一致；R2E datalad6b6f、orange50f6 有合理替代解被拒的实跑证据。另21题保留风险判断，不能全部写成已证实误拒。
- **原 gold 有缺陷但已有有效替代正对照的旧问题不都算“仍待处置”。**R2E numpy5e83／d805、scrapy7545／e938 已采用替代对照，其旧缺陷及修订版分数保留，不因此降为无法探针。
- 同仓跨题答案关联、数据划分和公共控制面是另外的共用条件。没有把机械命中逐一计为已经发生的泄漏，也没有把公共链路疑点乘以120。本表不是全量安全或留出划分认证。

**R2E有16题尚无完整质量结论**，不能标“暂未发现问题”。其中 numpy2f4a 已有资源配方未采用的运行问题，所以“尚未完成调查”与“已发现环境问题”可以同时成立。SWE72题都有静态审查，但只有39题已有正式 actor 身份的开发操作证据；其余33题没有实际开发验证，不代表已确认缺依赖。
