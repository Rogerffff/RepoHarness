## 0. 一个前提：SWE-Gym 现在没有"给题目追加参考测试"的机制

`reference_bindings_v1` 只能重新绑定已有的参考分组，代码断言绑定必须落在原有的 F2P/P2P 之内；R2E 的"受信修订单 → 材料版本"是 R2E 专用的。所以凡是"补断言 / 扩测试选集"的裁决，**方向可以现在定，但落地需要新建一个带版本的 SWE-Gym 题目修订机制**。它会改变评分依据，属于公共契约，按风险划为"先不修"。在机制建成之前，用第 2 节的事后审计兜底。
