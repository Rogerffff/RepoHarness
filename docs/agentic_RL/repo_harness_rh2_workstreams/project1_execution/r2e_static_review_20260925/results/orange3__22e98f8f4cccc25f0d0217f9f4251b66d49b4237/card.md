## 1. 目标、版本与用途

- **要修的问题**：`Orange/widgets/data/owcreateclass.py` 中的 `unique_in_order_mapping`。它用排序置换本身去索引 `inv`，应当先取逆置换。只要元素首次出现的顺序对应的置换不是对合（自身的逆），结果就错。题面例子是 `[2,3,1]`：现在得到 mapping `[2,0,1]`，应为 `[0,1,2]`。
- **版本**：R2E-Gym subset `e8b9fcbc`，base 为 `96fda39b`，没有材料修订；派生镜像配方 `r2e_derive_v1`。期望 23 键全是 PASSED，其中目标键只有 1 个：`TestHelpers.test_unique_in_order_mapping`。
- **建议用途**：`development_diagnostic`。在当前题面下，**不宜用于能力测量，也不宜作探针候选**，因为题面已经给出了修法。
