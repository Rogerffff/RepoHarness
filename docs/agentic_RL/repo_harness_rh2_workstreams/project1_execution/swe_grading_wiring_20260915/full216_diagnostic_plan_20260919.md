## 4. 新机器建议

推荐 x86_64 Linux、可运行真实 Docker 与读取 cgroup，**实际分配 16–32 vCPU、64 GiB 内存、1.5–2 TB SSD/NVMe**。无需 GPU 算力；若平台要求带 GPU，选满足 CPU/内存/磁盘的便宜机型即可。

磁盘是留给镜像池、可写层、派生资产与日志的余量建议，不是已测出的精确需求。800 GB–1 TB 也可按仓库分批拉取/清理，但会增加调度和下载时间。初始从 4 个 worker 起，按实测调整；不能仅凭机器标称核数承诺一晚跑完。今晚不扩大 R2E 正式评分接线，不更改评分定义、参考清单或反作弊政策。
