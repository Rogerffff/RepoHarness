4. 耗时：一次评分中位 35 s、p90 452 s（pandas 安装 ~590 s、MONAI-1121 ~750 s）；峰值内存中位 243 MB。

**环境侧遗留（不是评分链缺陷，交 B 线清洗 / 流水线阶段）**

5. modin（6298、6937）：pytest 收集后在第一条测试前静默退出或挂死，gold 也如此，5 行全部 infra；根因 = Ray 按宿主 CPU 数起 worker（`MODIN_CPUS=2` 即恢复），见下表。

7. MONAI-3205（数据集下载）、moto-4799（真实 HTTPS）在 deny_all 下 gold 不过；MONAI-1121 需要派生镜像；MONAI-763 的集成测试在 4 GiB 内存内跑不完（shm 放大即 OOM）。
8. moto / pydantic 配方的安装段在原镜像上不生效（rc=2）；只影响需要重装的候选改动；派生镜像可解。

**评分语义 T0（早报待拍板，详见 batch4 impl_plan §9.6）**：候选进程 stdout 可伪造状态行 / conftest hook 满分（B 线 M2 实测）；正式链的 P-A 资格来源；A2 预算拆分（T1 建议）。

**modin 定向探针（`experiments/probe_modin_post_e2.sh` + 两次手工变体，e2 之后在同机器跑；日志 `runs/…/e2/probe_modin/`）**：

| 变体（fresh 容器，`--cpus 2 --memory 4g`） | 结果 |
| --- | --- |
| 默认（shm 64 MiB、pids 512，root） | 收集 3525 项后第一条测试前静默退出 rc=1，stderr 为空，`oom_kill 0`，pids 13/512 |
| shm 1 GiB | 同一位置挂死，600 s 被 timeout 杀（rc=124） |
