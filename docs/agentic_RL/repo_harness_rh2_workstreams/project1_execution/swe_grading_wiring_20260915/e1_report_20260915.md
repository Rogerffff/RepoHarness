## 4. 发现与含义

1. **D3 的真实代价是 overlay copy-up，不是 chown 本身。** dvc 镜像（33k 文件）首次 `chown -R` 180 s、随后再 chown `lib/` 只 1.6 s；打开内核 overlay `metacopy`（`echo Y > /sys/module/overlay/parameters/metacopy`）后同一操作 11 s，pandas 前缀（115k 文件 / 4.5 GB）5.5 s，`/testbed` 0.2 s。e1 主批的可信 setup 80–204 s 都是这一项。e2 与以后任何使用 D3=A 的机器都必须先打开该开关（runbook §0.5）；训练机若不能改内核参数，就要回到"派生镜像烘焙属主"或收窄前缀的方案——这是 D3 需要用户知道的新事实。
2. **安装段在离线下的真实状态。** 三题 `RH2_INSTALL_RC=0` 但 mypy 的 `pip install -e .` 因 build isolation 需要下载 setuptools 而失败（段末命令是 `pip install pytest…`，已满足所以 rc 0）；导入路径在 `/testbed` 是镜像构建期可编辑安装的结果，不是本次安装的结果。纯 Python 任务因此不受影响；改依赖或需重编译的候选（pydantic 的 `pdm.lock`、pandas）必须走 D4 预置。`install_rc ≠ 0 ∧ resolved` 在 e1 没有出现。
3. **测试退出码与判定的关系。** dvc gold `RH2_TEST_RC=1` 仍 resolved：同一测试文件里非参考测试失败，官方口径只看参考集合。这是预期行为，e2 账本会继续记录。
4. **参考集合与 parser：** 三题参考 ID 缺席 0、解析条数与官方一致（conan 70 条含 67 P2P）；v2 入口在真实镜像上无差异。
5. 内存峰值 ≤ 1.1 GB（dvc），远低于 4 GiB 限额；shm 64 MiB 未触发问题（MONAI-763 在 e2 单独对照）。
