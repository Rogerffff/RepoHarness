## 问题

- 期望映射 13 键里有 4 个 `FAILED`：`TestLogisticRegressionLearner.test_LogisticRegression`、`test_coefficients`、`test_learner_scorer`、`test_learner_scorer_multiclass`。gold 与 noop 都是 FAILED，参考 runner 也记 FAILED，R-f 对账逐键一致。
- 原因（gold 日志逐键读）：
  - `test_coefficients`：`sklearn/utils/optimize.py:243` 的 `result.message.decode("latin1")` 抛 `AttributeError: 'str' object has no attribute 'decode'`。镜像里是 scikit-learn 0.22.2.post1 + SciPy 1.7.3：lbfgs 在 heart_disease 上默认 `max_iter=100` 未收敛时，sklearn 0.22 假定 SciPy 返回 bytes 的 `message`，新版 SciPy 返回 str。
  - `test_LogisticRegression`：交叉验证里同一异常路径之后，预测数组里是未初始化的值（`6.43e-310` 之类），`accuracy_score` 报 "mix of binary and continuous targets"。
  - `test_learner_scorer`、`test_learner_scorer_multiclass`：最重要特征名不符（'major vessels colored' vs 'chest pain'；'aquatic' vs 'legs'）。推断为同一组依赖版本下优化结果不同，未单独验证。
- 性质：**依赖版本不兼容导致的 FAILED 被写进了期望**（R2E-Gym 构建镜像时 `uv pip install scipy scikit-learn` 解析到的组合）。不是缺依赖，也不是网络 / 资源问题。
