### Error When Using L1 Penalty with LogisticRegressionLearner

When configuring `LogisticRegressionLearner` with `penalty='l1'`, an error is raised because the solver does not support the L1 penalty.

**Example Code:**
```python
learn = LogisticRegressionLearner(penalty='l1')
model = learn(iris_data)
```

**Error Message:**
```
ValueError: Solver lbfgs supports only 'l2' or 'none' penalties, got l1 penalty.
```

**Expected Behavior:**
The learner should automatically select a solver that supports the specified penalty, allowing the use of `penalty='l1'` without errors.
