每题最终落到三种结论之一：

- 疑点已消除，可申请转第1类；
- 问题和修法已明确，转第2类并交接；
- 仍有具体问题，写明缺什么证据、下一条命令或需要谁决定。

规则按[统一标准 v1](../task_screening_standard_v1_20260925.md)执行。v1 已授权的 R-a 至 R-f 修订模板，本目录只起草并做诊断验证；正式修订版本由第2类线程经 D6 入口落地。
