高层看到的四个问题

每行一句话；细节见下方图与表。

执行宿主风险
MiMo报告：常驻多租户宿主池，阻塞操作放后台线程；代码：每会话一个 Ray task
RH2全部编排和模型代理都在一个进程里；实测代理线程每秒最多约 1.6 轮（老 Xeon）到 9 轮（M5）
推理喂给量风险
MiMo代码：32 个 SGLang 副本，按会话粘性路由
RH2模型调用上限 32；默认 1 个引擎；路由不按会话粘性
环境准备可优化
MiMoK8s Pod 每会话，申请 0.5 CPU；镜像预制，运行时只核对
RH2本机 docker，每次现场清 Git、chown；非模型时间是求解的 3.2 倍
训练闭环缺口
MiMo报告是生产运行；公开代码是可运行的配方
RH2rollout→训练→发布→评测→恢复从未端到端跑过；启动器过时

3.2×非模型时间 / 求解时间29,273 秒对 9,154 秒；评分侧 chown 占非模型时间 64%，actor 侧 chown 11%，两侧 Git 清理共 8%，评分安装 5%（需要编译缓存的只有两道 Pandas）。
24% → 69%求解时间占比（投影）把属主、Git、编译缓存做进镜像后的估算，残余量取 CPU 实验实测；尚未在 GPU 上实测。
