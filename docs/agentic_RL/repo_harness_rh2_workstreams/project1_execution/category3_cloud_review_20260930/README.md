### Dask9378：建议实现路线不等于唯一验收目标

原题直接比较 `da.ones_like(array)` 与NumPy的mask行为，然后说“perhaps the simplest thing…”是在 `dask.array.ma` 增加函数。原公开docstring还写明返回与输入相同的shape和type。只修顶层的候选已实测保留mask，并通过320项旧creation测试。

因此，`da.ma` 的模块分工和既有函数能支持这条路线，却不能排除顶层路线。作者和复核者要求两种读法有“同等”依据才算歧义，也高于现规则的“两种读法都有依据”。**把建议改写成强制API，是目标选择；不能先改题面，再用新公开读者认为清楚来倒推原选择已获依据。**

具体后续：核查原版本公开文档是否另有排他性API约定。若仍无，明确选择“强制新增ma API”还是“接受能完成公开mask目标的路线”，并据所选版本修订。此项是本批确实可能需要选择任务目标的事项。其它已明确修法不必一起等待。

证据位置：固定快照 `tasks/dask__dask-9378/result.md:14,50–58`、`review.md`、`review_initial.md`，以及[本次四题复核](first_swe_review.md)。

## 方法需要怎样调整

总体保留现有方法：读原件、明确公开行为、候选对照、原评分与修订诊断分开、独立复核、归档。**不需要推翻重做首批，也不需要把每题扩成无限测试矩阵。** 主要调整四项：

1. **从问题到修法的证据必须闭合。** 每个重要疑点写清公开依据、决定性实验、正确行为、候选为何错误/为何合理，以及修订后预期。候选叫“退化”不构成错误证明，未来上游做法也不是原题公开要求。
2. **完整交接已知缺陷。** 替代正对照能通过，只说明存在正确实现；还要检查已知错误候选是否被放过。不得用自然写法、出现频率、耗时或复核轮数替代严重度判断。
3. **转类与最终验收分开。** 3→2无需先完成全部actor验证或正式修订机制；但目标未定、正对照仍无可信依据、关键证据缺失时，也不能转类。第2类必须接收全部重要余项，修好后再进第1类。旧“已知漏判但靠事后审计做普通比较”的表述应撤下。
4. **按实际代码与可取回证据交接。** 云端brief称D6已支持任意测试补丁替换不准确：本地主干当前首片仅`append_mypy_p2p`。诊断`--materials`并不等于正式actor消费已落地。正式替换是已获总体授权下的后续实现项，不要再请求整体授权，也不要把它写成已完成。

归档方面，每个有结论的实验小组完成即保存输入/版本、候选、测试、账本、完整日志与清理事实，并确认持久化成功，之后才标完成或暂停实例。不要等长报告写完再归档。仅保存SHA不能恢复字节；大日志可压缩或放持久存储，重要小工件不要因目录名被统一排除。已丢失部分如实保留，按其是否影响当前决定选择补跑，不机械全量重跑。
