Stage 16G.3B · run_public_command — 执行计划

来源：执行计划 §9 · 前置：3A 共享底座必须完成 · 核心交付：主训练默认 profile 中的公开命令工具 run_public_command

介绍

3B 是 16G.3 给模型新增的第一个可调用工具。它专门用来跑"非测试"类公开命令：公开仓库检查（git status 等）、公开内容搜索（受限 rg）、公开 Python smoke（python -m compileall）、任务声明的公开命令。不承担定向测试主路径（那是 3C 的事），不承担临时脚本（那是 3D 的事）。

1 · 工具契约（计划 §9.1）

run_public_command(
    command_profile_id,
    args=None,
    cwd=".",
    timeout_sec=60,
    purpose=None,
)

字段名可在实现时微调，但必须表达：

  1. 模型请求的公开命令 profile（command_profile_id，必填）
  2. workspace-relative cwd
  3. timeout_sec
  4. 可选 purpose：模型说明这次命令的公开诊断目的（写入审计，不影响执行）

2 · 自由裸 argv 不放 — 必须强制 profile 路由

这是 3B 最容易被实施时简化的地方。计划 §9.1 明确：

核心约束：必须以 command_profile_id + structured args 为主路径。裸 argv 不能作为自由命令入口；只有当 argv 能规范化匹配到某个已启用 PublicCommandProfile，并且参数满足该 profile 的 allowed_args_schema 时才允许执行。字符串 command 只能作为兼容层或模型提示中的自然语言示例，不能成为 executor 内部安全事实来源。

2.1 验收 summary 必须显式写入

raw_freeform_argv_supported=false
argv_must_resolve_to_enabled_profile=true
unknown_argv_rejected=true

2.2 必须包含的 4 个负例

argv预期处理路由提示
["bash","-lc","..."]denied不要用 shell 包装；用 profile 调用对应工具
["python","-c","..."]denied 或路由建议safe_alternative_tool="scratch_python"
["pytest", ...]deniedsafe_alternative_tool="run_project_test"
["git","log"]deniedGit history 作弊路径，无替代

3.1 模型把 pytest 命令传进来时的路由

这种情况非常常见。run_public_command 不沉默拒绝，而是返回结构化路由：

{
  "status": "denied",
  "reason_code": "route_public_test_to_run_project_test",
  "safe_alternative_tool": "run_project_test",
  "safe_rewrite_example": "run_project_test(selector=\"tests/test_x.py::test_y\")"
}

4 · 与 execute_bash 关系（计划 §9.1 末段）

run_public_command 是正式 swe_public_core 工具，不是 execute_bash 的别名。

  • run_public_command — 新主路径，进 core profile（前提：3A 完成且 backend 可隔离）
  • execute_bash — legacy / extended / diagnostic，不应重新进入主训练默认 scaffold

这意味着 16G.3B 不是"把 execute_bash 重命名"或"扩展 execute_bash 接口"，而是另起一个独立 handler，共享 3A 底座。execute_bash 留作 16G.4 / 兼容用途。

5 · 模型可见说明（计划 §9.3）

工具 description / public_safe_description 必须写清：

  1. run_public_command 用于公开诊断，不用于文件修改
  2. 文件修改使用 apply_patch / write_file
  3. 文件读取优先使用 read_file / grep / glob_files / symbol_search
  4. 测试优先使用 run_project_test
  5. 不能用它访问 hidden evaluator / Git history / runtime-private / 宿主路径 / 网络

6 · 8 项 probe 验收（计划 §9.4）

1允许公开仓库检查：一个允许的公开仓库检查命令返回 stdout / stderr / exit code
2允许公开 compile / smoke：一个允许的 compile / smoke 命令返回 exit code
3pytest 路由到 run_project_test：一个 pytest 命令被路由到 run_project_test 或返回可学习替代建议（含 safe_rewrite_example）
4破坏性文件命令拒绝：一个破坏性文件命令（rm / chmod / git reset --hard）被拒绝，并说明应使用结构化文件工具
5Git history 拒绝：一个 Git history 命令（git log / git show / reflog）被拒绝
6网络命令拒绝：一个网络命令（curl / wget / pip install）被拒绝
7路径越界拒绝：一个尝试访问 hidden marker / runtime-private / 本机绝对路径的命令被拒绝
8artifact 可见性：tool result 公开摘要无路径泄漏，raw artifact 不返回给模型

7.2 16G.3B 完成意味着什么

取决于 3A 落在哪个终态：

3A 终态3B 完成后 run_public_command 行为
终态 A（Docker + deny）真实执行公开命令，进 swe_public_core，模型 turn 可调用
终态 B/C（本机或纯 schema）schema 注册 + scaffold 暴露，但 executor 返回 behavior_not_enabled_until_docker_backend_ready，不进 core profile（类似 16G.2A 的 schema-only 模式）
