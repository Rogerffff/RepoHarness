2. 最重要的结论与对上一轮解读的补充

组基线与跨题批次基线的比较，不只是“哪个更懂题目难度”。固定回答数时，组采样同时改变了题目覆盖、基线目标质量和有限样本估计噪声。组均值更接近本题真实成功率，不代表梯度方差更低。

此前“跨题均值不能像 V(h) 那样区分题目和中间状态”的说明仍然成立，但不能据此直接推断它的方差更大。同样，本文没有比较完整 SAO 或 FlashREINFORCE，也没有证明 critic 不必要、GRPO 落后或 SWE 应改为单轨迹。

抽题是有放回的；实验总共只有 256 个 prompt 状态，不能把 1024 次独立抽取写成 1024 道不同的题。本文联合比较基线与回答分配协议，不是在同一份既定 group 数据上只切换减均值方式。

为匹配期望梯度，使用 leave-one-out（LOO）：每个回答减去其余回答的平均 reward。Group 用同组其余 G-1 个，Batch 用其余 N-1 个。

6. 两个策略模型为何给出相反结论

6.1 每题独立 logit

每个 prompt 有自己的参数，score 为 (R-p(x))e_x。不同题更新不同坐标，覆盖更多题重要；本题均值又可能偏离 b*=1-p。所有测试的分布及组大小下，初始梯度方差均由 Batch 协议更低。

6.2 单一共享 action 参数

共享参数选择 U∈{-1,+1}，环境成功概率为 p0(x)+0.05U。在初始化，score 为 U，每题期望梯度均为 0.05，本题均值恰好是最优基线，B=0。因此难度差异足够大时，组基线可以获益。

这不是“参数共享必然 B=0”；是所选策略与 reward law 联合构造出的性质。两个模型同时改变基线质量与梯度结构，不是只隔离某一个因子的实验。

7. 训练实验、统计与复现边界

论文不只计算初始方差，也进行了 CPU contextual-bandit 策略优化：每次更新 1024 回答、共 400 更新；目标为期望奖励减去相对初始策略的 KL 惩罚，使用 SGD 与精确 KL 梯度。精确最优解已知，因此指标为 J*-J，而非 LLM benchmark 分数。

16 个难度设置为 12 个代表性分布加 4 个均值/方差匹配的形状。每个方法从相同七档学习率中独立调参，再用未参与选择的 seed 评测；独立 logit 为 20 个评测 seed，共享模型为 100 个。组大小为 2/8/32。

hard-heavy mixture 下，G=8 的最终 objective gap 比：独立 logit 为约 4.39（Batch 更好），共享模型为约 0.41（Group 更好）。后者表示剩余优化误差小约 59%，不是准确率高 59% 或样本效率翻倍。部分其他设置的置信区间无法判定谁胜出。

初始冻结策略下的方差排序不自动决定最终训练排序。论文的置信区间是逐项、未作多重比较修正，并以本次已选择学习率为条件；七档搜索不是证明全局最优调参。

附录 B.4/B.8 报告了 Monte Carlo、有限支持枚举、独立实现和逐 seed 数据校验，并称提供 supplementary archive。本次没有取得和执行该 archive，不能把这些报告计为本次独立复现。

8. 这份补充不能证明什么

理论假设冻结 on-policy 策略、E[z|X]=0、条件独立与必要矩有限，明确不涵盖经验标准差归一化、clipping、policy lag、token masking 或长度相关 loss 权重。度量为原参数坐标中的梯度方差，不是 Adam 预处理后更新的最优性。

因此：

  • 它支持“单轨迹 + 跨题均值可能更高效”的理论可能性，不证明 FlashREINFORCE 完整算法在 LLM 中一定优于 GRPO。
  • 它也不是 SAO critic 或 GAE 的对照，不能证明两者必要或多余。
  • 同回答数不代表同 token、同 GPU-hour 或同真实耗时。多轮 SWE 还涉及环境初始化、prefix cache、长尾等待、失败重试等成本。
  • 二元 reward 下，同题组全同奖励的概率是 p^G+(1-p)^G；例如 p=0.9、G=8 时约 43.05%。这会产生零贡献组，但在未按奖励重采等理想设置里，其他组在期望上补偿，不能仅据此认定估计有偏。

9. 对项目实验设计的影响

以下为建议，不更改已有决策。

第一，把“是否使用 critic”“如何构造 reward baseline”“每题采几条”“如何处理异步 ratio”“loss 如何归一化”分开记录。比较 Flash 与现有方案时，应明确改变了哪些维度。

第二，正式效果比较必须控制总采样预算并各自合理调参；同时报告 prompt 抽取数、独立题数、轨迹数、生成 token、GPU-hour 和 wall-clock。不要让含自身均值的不同缩放、优化器参数或评测 seed 选择掩盖采样设计的差异。

第三，可以先用一小批重复采样轨迹做冻结策略诊断，估计不同抽样/中心化方式下梯度或梯度投影的波动，并观察组内零信号、长度和题型差异。这个诊断只能帮助选择实验，不能替代实际训练；若无法负担完整梯度，应明确投影只提供局部证据。

第四，SWE 题目异质性同时影响基线收益与题间梯度差异，两个效应可能相反。不能因“仓库和难度很多样”直接批准 group 或 batch。最终应由同模型、同 harness、同 reward 下的受控实验决定。
