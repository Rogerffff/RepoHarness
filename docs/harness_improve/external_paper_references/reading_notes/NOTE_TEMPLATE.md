## 5. 训练目标与实际训练语义

先用文字解释，再按原文给必要公式并解释每个符号。

- 训练样本单位：prompt / response / trajectory / segment / token；每题采样数。
- reward 来源、合成方式和尺度；advantage、baseline / critic、group 统计对象。
- 新策略、行为策略、参考策略、teacher 的身份；IS ratio 与 clipping 的具体作用对象。
- token mask：assistant / thinking / tool observation / compaction；哪些 token 进 loss。
- loss 分母：token / trajectory / group / batch；变长轨迹怎样加权。
- 失败/截断/过滤样本：是否参与 group 统计、梯度、补采；不要合并这三个问题。
- KL、entropy、off-policy 修正、更新次数、batch / minibatch、优化器、学习率。
- 若有 OPD：teacher/student 分布、同/异 tokenizer、full-vocab/top-k/sampled-token、logprob 取得方式、KL 方向、特权上下文、teacher 更新规则。
- 若算法未披露：注明已查范围；不得从模型家族、框架默认值或上一篇报告推成当前事实。
