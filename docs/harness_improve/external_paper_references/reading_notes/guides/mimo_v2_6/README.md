# MiMo-V2.6 交互带读

这是 MiMo-V2.6 技术报告的交互讲义，不是训练平台。第一版完整整理此前已经讲过的四个单元，并根据全文设计后续六个单元的阅读地图。后续单元只展示范围、核心问题与呈现计划，不标为已经讲解。

## 打开方式

GitHub 的文件页展示源码，不是运行中的网页；本次没有启用 GitHub Pages。

- 下载本目录后，在现代浏览器中打开 `index.html`；同目录保留 `guide.css` 和 `guide.js`。
- 或用 Python 3 构建单文件版本：

```bash
python build_standalone.py --output MiMo_RL_Interactive_Guide.html
```

随后直接打开生成的 HTML。运行讲义不需要 Python、联网、CDN、外部字体、API key 或模型服务。原文 PDF 不包含在页面或仓库中；可以通过“原文对照”选择本地文件。桌面宽屏采用左右对照，窄屏使用侧栏。浏览器原生 PDF 查看器可能忽略页码参数或阻止嵌入，页面提供新标签打开方式；也可在独立 PDF 软件中按页码阅读。

## 阅读功能与信息边界

原文事实、解释性示例、未披露／未验证项使用不同标签。每节保留原文页节定位，正文不密集重复文件引用。交互计算是解释工具，不能当作训练实验、论文消融或项目效果预测。图表为讲义示意；不从示意图读取论文的精确曲线。

- 目录、全文地图、章节搜索（Ctrl/Cmd+K）、字号与专注模式。
- 每个单元手动标记已读；四个完成讲义与六个规划单元分别计数。
- 每个单元可写个人笔记，支持 JSON 备份／导入、Markdown 导出。
- 笔记仅保留在当前浏览器可用的本地存储或本次会话内，不写入 GitHub，不上传 PDF。移动文件、更换浏览器、隐私模式或清理数据可能使本地记录不可用；请定期导出 JSON。
- 打印只包含四个已讲单元、当前示例状态及个人笔记，不把规划卡当作完整章节。可折叠的解释在打印前展开。
