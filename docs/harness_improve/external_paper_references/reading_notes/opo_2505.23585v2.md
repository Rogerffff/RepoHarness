# OPO v2：精确 On-Policy 与最优 Reward Baseline——SWE-2 配套来源精读

OPO 把严格按当前策略采样、每次更新后重新采样，与长度加权 reward baseline 组合成不需要 critic、reference policy 或显式 KL/entropy 项的训练方法。论文在 DeepSeek-R1-Distill-Qwen-7B 的数学任务上比较 on/off-policy 和 GRPO/OPO，并在 1.5B 上补充 Reinforce++ 训练曲线。长度加权公式与 SWE-2 相同，但 OPO 的实际实验强调 exact on-policy，SWE-2 明确采用 off-policy；不能因公式相同就把两篇配方视为一回事。原文有正结果，也有 AIME2025 小 k、MATH500 多样性指标等未胜出的比较，且没有提供充分的总计算成本或多随机种子证据。

## 2. 论文比较的不是所有形式的 async RL

作者指出，生成时与优化时的策略不一致、同一批数据多次更新，会使常见 GRPO/PPO 训练偏离严格 on-policy。OPO 要求**每次 policy 更新所用样本由该次更新前的当前 policy 生成；更新之后重新采样**。它不使用额外 value/reference model，也不在其默认目标中加入 KL 或 entropy 正则。[P，§2–3，pp.2–5][P3]

这不等于证明所有 staleness 都有害，也不表示任意异步执行都违反 on-policy：环境初始化、工具调用、评分和同一固定策略下的多请求可以并发。论文没有研究 miles 式长程外部 agent 的完整轨迹生命周期、版本恢复或多轮工具缓存。

背景的 PPO 公式含 old/current likelihood ratio 与 clipping；GRPO 背景优势含组标准差归一化。OPO 去掉 reference/critic，不意味着它是其他论文中命名相近的 OPD、OPSD 或 SDPO；这里没有教师概率蒸馏。

## 3. 训练目标、baseline 与近似条件

### 3.1 总体最优 scalar baseline

给定 prompt $x$，记 $z(y)=\nabla_\theta\log\pi_\theta(y\mid x)$。对 normalized on-policy 样本，$\mathbb E[z]=0$，所以不依赖当前 response 的 baseline 不改变期望 policy gradient。最小化梯度向量的总二阶矩可得

$$
b^*(x)=\frac{\mathbb E[R(y)\|z(y)\|^2\mid x]}{\mathbb E[\|z(y)\|^2\mid x]}.
$$

Appendix A 展开这一结论：梯度均值与 baseline 无关，方差里依赖 baseline 的部分是 $\mathbb E[(R-b)^2\|z\|^2]$，对 $b$ 求导即可。分母需非零且相关矩存在。**最小 reward 残差方差的 $\mathbb E[R]$ 不一般等于上述最小梯度方差的 baseline。**[P，§3、Appendix A，pp.3–4、12][P4]

### 3.2 从 sequence score 到长度代理

sequence score 为各 token score 的和，平方范数含交叉内积。作者通过不同 token score 近似正交、token 级范数具有相近分布等假设，近似认为 $\|z(y)\|^2$ 与 response 长度 $|y|$ 成比例。由此形成

$$
\widehat b(x)=\frac{\sum_{i=1}^{K}R_i |y_i|}{\sum_{i=1}^{K}|y_i|},\qquad
A_i=R_i-\widehat b(x).
$$

这是便宜的近似，不是从“任何自回归序列”就能严格推出的定理。跨 token 相关、不同结构 token、高梯度异常轨迹等都可能使代理偏离原总体最优权重。[P，§3，Eq.(9)–(12)，p.4][P4]

OPO 的经验目标使用完整 response 的 log-prob 与这个优势；实际优化按 score-function surrogate 解释，采样分布和计算优势不应被再次作为普通可微目标一路求导。论文没有为 RepoHarness 式 tool observation、harness rewrite、子代理和 compaction 提供对应 mask／分母规范。

同组经验 baseline 依赖自身 sample；原总体常数最优性不能不经说明地直接成为有限组经验估计器的无偏保证。这个区别与本文实现是否实践有效是两个问题，详细见 [独立基线核查](swe2_baseline_theory_checks.md)。

### 3.3 算法更新单位

Algorithm 1 的结构是：取 prompt batch → 当前 policy 每题采样 $K$ responses → 计算 rule reward 和长度加权 baseline → 一次 policy update → 重新采样。它不通过在同一旧 batch 上重复小批更新增加消费次数。[P，Algorithm 1，p.5][P5]

不能将“一个 batch”自动理解为一个分布式 microbatch；也不能从公式符号恢复论文未说明的全局 token normalization、梯度累积和并行布局。本文没有读当前 trainer 实现来补这些字段。

## 4. 训练数据、模型与评测协议

### 4.1 两组主要实验应分开

| 实验 | 起点与数据 | 核心配置 | 关键对照 |
| --- | --- | --- | --- |
| §4.1 exact on-policy vs off-policy | DeepSeek-R1-Distill-Qwen-7B；基于 OR1 数学数据，原始约 48K unique，并离线滤全对／全错 | 最大训练长度 8K；batch 256 prompts；每题 16 responses；lr $10^{-6}$；500 training steps | on-policy mini-batch 256；off-policy 128，并使用 0.2 clip、0.001 entropy 系数 |
| §4.2 GRPO vs OPO | 上述模型经过额外 long-CoT SFT；作者称 SFT 阶段排除与 OR1 的重复项，并用剩余约 25K 样本做 RL | 最大训练长度 24K；batch 256；每题 8 responses；exact on-policy；KL/entropy 系数 0；本组 lr 未单列 | 主要比较优势估计，但 GRPO 的组标准化与 OPO 无标准化也同时不同 |
| Appendix B Reinforce++ vs OPO | DeepSeek-R1-Distill-Qwen-1.5B | 最大训练长度 8K；batch 256；exact on-policy；无 KL reward 项 | 训练 reward / entropy 曲线；没有完整外部 benchmark 表 |

来源：[P，§4.1–4.2，pp.5–8；Appendix B，p.13][P5]。OR1 的最终保留数、SFT→RL 分支的 long-CoT SFT 完整配方、全程重试／无效数据量未充分披露。不要把 48K 原始数据、25K SFT→RL 分支数据和实际有效消费量相加成一个训练总量。

reward 使用 Math-Verify 式规则化正确性判断。这是数学答案任务，**没有 SWE 镜像、PR、候选 patch 或外部工具交互环境**。

### 4.2 比较协议的混杂边界

on/off-policy 实验不只是把一个 staleness 开关改掉：mini-batch、每 batch 的数据重用方式以及 clipping／entropy 设置也不同。作者在 Table 1 邻文称采用相同 optimization steps，但没有给足调度计数细节；相同“500 training steps”不能直接当作已核验的等采样量、等数据重用或等总计算。结果支持论文所比较配方的差异，不能自动分解成纯策略陈旧度的因果作用。

GRPO/OPO 实验虽然共同保持 exact on-policy，但更换 baseline 时也更换组标准差处理。不能将全部收益说成“仅长度权重”而不提标准化。

### 4.3 评测

评测为 MATH500、AIME2024、AIME2025；生成最长 32,768 tokens、temperature 0.6、top-p 1。MATH500 每题采 8 条；AIME 每题采 16 条，报告 pass@1/2/4/8（AIME 另有 pass@16）。汇总的是最后五个 checkpoint（420、440、460、480、500）的结果平均，**不是五个独立随机种子的置信区间**。[P，§4，pp.5–8][P6]

论文正文以高 entropy、低到初始 policy 的 KL 和较低重复率讨论 diversity / alignment tax。此 KL 是相对初始策略的 policy shift，**不是 SWE-2 图中的 inference–training KL**，两张图不能直接当作同一稳定性指标。

## 6. 曲线、消融与附录

### 6.1 Figure 1：on/off-policy

reward、response length、entropy、KL 同时显示。作者观察 off-policy entropy 更快收缩、到初始 policy 的 KL 更高，而 exact on-policy 更稳定。该实验比较了完整配方，不把曲线差异拆成单一 clipping 或数据重用作用。[P，Fig.1，p.7][P7]

### 6.2 Figure 2：GRPO / OPO

共同 exact on-policy 下，OPO 具有较低 policy shift，entropy 总体相近，作者据此认为长度加权基线较有效。原文没有给每个 checkpoint 的梯度协方差、独立重复方差或以方差下降为中介的因果证据；不能把“KL 更低”改写成“实测梯度方差降低某百分比”。[P，Fig.2，p.7][P7]

### 6.3 Appendix A/B 与 Figure 3

Appendix A 是总体最优 baseline 证明，与有限样本替换后的偏差问题分开。Appendix B 在 1.5B、8K、batch 256、同样 exact on-policy 的设置下，比较 OPO 与 Reinforce++ 的训练 reward 和 entropy。曲线支持作者所示运行中的 OPO 优势，但正文将更完整比较留为后续工作，未给外部 benchmark、全部超参或总资源表。[P，pp.12–13][P12]

## 7. 成本、开放性与未披露

没有 critic/reference 能减少相应参数和前向计算，但 exact on-policy 放弃部分旧数据重用，可能增加采样压力。**论文没有提供足够的端到端 GPU-hour、硬件数量、时长和不同配方时间成本，不能把结构简单等同于整体一定更便宜。**

论文给出 verl 文档入口与模型／数据背景，但本轮没有下载 checkpoint、重建训练集、运行代码或核对当前 commit。最关键缺项包括：SFT 完整来源和规模、筛选后实际训练集、采样/更新计数的充分对应、全局 loss 分母、分布式并行及失败处理、独立重复与置信区间。背景提及偏好对齐，不代表本文训练了 preference reward model 或进行安全评测。

## 8. 与 SWE-2 及 RepoHarness 的关系

| 层次 | OPO | SWE-2 |
| --- | --- | --- |
| 总体 baseline 理论 | score-norm² 加权 | 同一结构并引用 OPO/Greensmith |
| 便宜经验式 | response length 加权 | trainable length 加权，具体 mask 未公开 |
| 实际采样/更新 | 强调 exact on-policy | 明确是 off-policy |
| reward | 数学规则正确性 | 成功减 effort 相关混合成本 |
| 证据 | 数学训练、pass@k、entropy/初始策略 KL | coding 系统发布、行为、inference–training KL |
| 泛化边界 | 无真实 SWE harness/工具执行实验 | 无完整可复现优化器与资源配置 |

读者可借鉴其 baseline 候选和比较方法，但不能把已有 miles 改为单次更新就称为 OPO 复现，也不能只替换组均值就保证 variance-optimal。实际需要先固定逻辑轨迹、action mask、分组、标准差、分母和 off-policy 修正，再做小型参考计算与受控对照。
