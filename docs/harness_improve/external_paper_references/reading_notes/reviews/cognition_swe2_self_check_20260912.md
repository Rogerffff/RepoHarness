## 2. 真实执行的检查

本地用 Python/NumPy 读取 JSON，静态提取网页对象，不执行下载的 JavaScript；用 PDF 工具提取和渲染原文件，不用 OCR。执行了：

- 七类行为数据按模型求和，区分 steps、output、thinking；与 leaderboard 的另一套 token 数并列，不消解差异。
- 成本和步骤比例算术：58.0317%、81.1898%、64.1924%，与原文约数相容。
- 48 个身份／语言条件区间的端点、模型顺序和 renderer 核对；不是重新 bootstrap 原始实验。
- 983 个散点与 renderer 的 yMax 过滤对账：944 个进入绘制，39 个被排除；对完整及筛后数组分别计算 Pearson。
- 四动作 softmax 的全部 $4^n$ 组枚举，n=2/4；验证普通组均值偏差、长度加权同组的非统一缩放，以及 iid 条件下排除自身的期望关系。

## 4. 自查中的修订

首次数据检查曾以正文概括为依据尝试断言48条区间都跨零，断言失败后回看数组、模型顺序和直接绘图代码，最终改为报告三项不一致；没有改动来源数据。

初步散点阅读主要依据视觉相关性。对照 renderer 后发现隐藏的 y 过滤，因此新增全量／显示子集区别和本轮描述性 Pearson 计算。没有把显示数组当完整训练分布，也没有臆造被滤点的原因。

逐表复查 OPO 后，删除第二实验组未直接披露的学习率，并将作者声称 same optimization steps 与我们未检查的实际调度计数分开。结果表保留所有小 k 和多样性未胜出项。
