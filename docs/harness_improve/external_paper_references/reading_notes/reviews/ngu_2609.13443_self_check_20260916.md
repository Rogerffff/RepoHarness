## 已做的解释修正

- 说明本方法的 centered advantage 与带组标准差归一化的 GRPO 有区别。
- 区分首次抽题分布、生成成本分布、有效更新分布。
- 区分在线追加采样、静态初始难度分配、永久删除易题三种机制。
- 用固定 q、独立采样的自拟模型推导实际期望采样数，明确 K/(1-p) 不是所有题的实际均值或硬上限。
- 重试历史进入统计，不代表作为上下文反馈给下一次模型调用。
- 旧样本参与 baseline 与进入 loss 分开；博客优势算术更正为 1/2。
- 说明 anchor positives 的负号、二值奖励范围，以及“优势和为零”不等于无偏。
- 对照 Algorithm 1，指出博客的部分测试示例不能解释成严格超过历史最佳值。
- 将数学实验实际增益写成百分点；3 seeds 标准差不冒充置信区间。
- 明确 SWE 的现象分析不是在 SWE 上验证 NGU 的训练实验。
