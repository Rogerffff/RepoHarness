## 3. 从草稿和旧材料中重点收紧的判断

**DIS 不是完整 SAO。** GRPO+DIS 是原文正面对照；单纯 n=1 没有 critic/有效基线也不是同一方法。

**同128条轨迹不是等计算。** prompt 抽样位置不同，critic计算不同，长度可能不同；无GPU-hour/墙钟计时不能声称SAO在八卡更便宜。

**公式端点与参数不能混写。** 数学 ε=(0.3,5.0) 按 P3 是 ratio∈(0.7,6.0)，coding为(0.2,4.0)；第三方README的直接band不是作者公式的自动翻译。

**Stop-gradient 是真正的披露缺口。** 本稿提供字面求导与固定权重求导的差异，但明确为读者推导；没有宣称作者写错实现，没有用项目 faithful DIS 约定回填原文。

**Value pretraining 不是已恢复的数据配方。** 只发现扩大corpus的主张与10-step warmup；没有数量、目标细节或规模消融。TIR三轮SFT不自动等于专门value预训练。

**400步后分化不是SWE结论。** Fig.3仅三项数学benchmark；90步VAPO与160步GRPO崩溃也只限特定实验，不能解释用户旧项目同一步数的故障。

**观测skip与segment压缩不能互相替代。** 附录step-level同时改变aggregation、mask、λ单位；不是skip开关的独立消融，也不是CompactionRL公式。

**原表异常保持原貌。** Table1工具开关结果、Fig.3 HMMT末点与Table1数值没有擅自合并；SPO比较主张不补成不存在的实验行。

**在线偏好结果完整但受限。** 第三阶段candidate set也变化；第一阶段对照更高；后段SAO较好不等于生产级持续学习、能力保持或全程优势。

**代码附查不扩大成整库审计。** 第三方helper的严格/非严格区间差异是固定文件事实；没有据此判断全部运行、detach调用或论文历史结果。
